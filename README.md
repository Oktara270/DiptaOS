## 🌟 About DiptaOS
**DiptaOS** is an open-source, Ubuntu-based Linux distribution designed to deliver a clean, modern, and fluid desktop workflow out of the box. Powered by a pure **Vanilla GNOME** session, it combines a centered floating taskbar, frosted-glass transparency, rounded window corners, and Material You aesthetics—while remaining lightweight enough to run smoothly on low-RAM machines.

---

## ✨ Key Features (v1.0 Beta 1)
* **Pure Vanilla GNOME Base:** Built on top of **Ubuntu 26.04.1 LTS** with stock GNOME Shell—free from default Ubuntu Dock conflicts.
* **Floating & Rounded Desktop:**
  * Centered floating taskbar with auto-hide (*intellihide*) support via **Dash to Panel**.
  * Modern Windows 11-style Start Menu powered by **ArcMenu**.
  * Frosted glass (*acrylic/mica*) transparency effects via **Blur my Shell**.
  * Consistent curved edges across all windows with **Rounded Window Corners**.
  * Clean circular icon set using **Tela Circle**.
* **Low-RAM Ready:** Pre-configured with **`zram-tools`** out of the box, tested and verified running smoothly on hardware with **4 GB RAM**.

## 💻 Minimum System Requirements
* **Processor:** 64-bit Dual-Core CPU (Intel Core i3 / AMD Ryzen 3 or newer)
* **Memory (RAM):** 4 GB minimum (ZRAM enabled by default)
* **Storage:** 20 GB free disk space (SSD recommended)
* **Graphics:** Any GPU supporting OpenGL 3.3+ (Intel HD/UHD Graphics works out of the box)

---

## 📥 Download & Installation
1. **Download the ISO (6.5 GB):**
   * [**Download DiptaOS 1.0 Beta 1 from SourceForge**](https://sourceforge.net/projects/diptaos/)
2. **Verify Checksum (Optional):**
   * Check the `.md5` file available on the [Releases Page](https://github.com/Oktara270/DiptaOS/releases/tag/v1.0-beta1) to ensure the download is complete and uncorrupted.
3. **Create a Bootable USB:**
   * Flash the `.iso` file onto an 8 GB+ USB flash drive using **Ventoy**, **Rufus**, or **BalenaEtcher**.
4. **Boot & Install:**
   * Boot from the USB drive, select **Try or Install DiptaOS**, and test the live environment or install it directly to your drive.
